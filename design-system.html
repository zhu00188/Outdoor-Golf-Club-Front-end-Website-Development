Color Palette Overview

The Golf Space color system is built around natural, earthy tones that evoke the outdoor golf experience. The primary green palette (#344e41, #a3b18a) represents the lush fairways and greens, while the accent orange (#f4732a) adds energy and warmth. Neutral grays provide balance and readability throughout the interface.

Breakpoints

Breakpoints define the screen width thresholds where the layout adapts to different devices. This responsive design system uses 6 breakpoints following Bootstrap 5 standards, ensuring optimal viewing experience across all devices from mobile phones to ultra-wide monitors. Each breakpoint triggers specific CSS media queries that adjust layouts, typography, spacing, and component behavior.
